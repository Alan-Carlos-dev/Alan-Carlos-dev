# 📌 Projetos

## 🌿 BioPulse System

Projeto pessoal em desenvolvimento que integra **Engenharia de Software, IoT e experimentação com plantas**.

O sistema utiliza um **ESP32** para aquisição de sinais e uma aplicação em **Python** para comunicação, tratamento e processamento dos dados coletados.

**Tecnologias:**

`ESP32` `C++` `Python` `Serial Communication` `IoT`

> 🔒 O código-fonte é mantido em repositório privado por se tratar de um projeto autoral ainda em desenvolvimento.

## 🛗 Otis Skymanage — FIAP

Projeto acadêmico desenvolvido em equipe durante o **Challenge FIAP**, a partir de um desafio proposto pela OTIS.

Minha principal contribuição foi no desenvolvimento da lógica de **RBAC — Role-Based Access Control**, estruturando papéis e permissões para diferentes tipos de usuários do sistema.

Entre os perfis simulados estavam:

- Vendas
- Fabricação
- Instalação
- Administração

Cada perfil possuía diferentes permissões de acesso às funcionalidades da aplicação.
